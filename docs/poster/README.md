# 🎓 AEGIS-Recon Academic Project Exhibition Poster

This directory contains the official, publication-ready, light-theme academic exhibition poster for **AEGIS-Recon** with Vidyalankar Institute of Technology (VIT, Mumbai) branding.

---

## 📄 Poster File Location
- **Self-Contained Poster HTML**: `docs/poster/project_poster.html`
- **College Logo**: `docs/poster/vit_logo.png`
- **Poster Generator Script**: `scripts/generate_poster.py`

---

## 🚀 How to View and Edit in Microsoft Edge

1. **Open the Poster**:
   - Double-click `docs/poster/project_poster.html`, or right-click and select **Open with Microsoft Edge**.
   - No web server or node installation is needed; it runs 100% locally and offline.

2. **Enable Live Editing**:
   - At the top of the page, click the **✏️ Enable Live Edit** button on the floating toolbar.
   - Click on any text on the poster (Student Names, Roll Numbers, Guide Name, Department, Abstract, Mathematical Formula, Problem Statement, Findings, etc.) to edit it directly in your browser.
   - Click **💾 Save Edits** to save your modifications into your browser's `localStorage` so your edits will persist even if you refresh or restart your computer.

3. **Export Your Modified Poster**:
   - Click **📥 Export HTML** to download a permanent `.html` file with your custom modifications baked directly into the code.

4. **Print or Save as PDF**:
   - Click **🖨️ Print / Save PDF** (or press `Ctrl + P` in Edge).
   - In the print settings dialog:
     - **Destination**: Choose **Save as PDF** (or select your college's poster plotter printer).
     - **Layout**: **Landscape**.
     - **Paper Size**: **A1** (for standard large-scale conference boards) or **A2 / A3 / A4** for report submission.
     - **Options**: Ensure **Background graphics** is **checked** so all color cards, badges, and logos are rendered vibrantly.
     - **Headers and footers**: Uncheck to keep the poster border clean.
